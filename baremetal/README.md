# Bare-metal reference designs for the 7100_2XAD9361 (Vivado / Vitis 2023.2)

| Path | Contents |
|---|---|
| `FMCOMMS5_PL/` | Vivado 2023.2 project of the Analog Devices `fmcomms5` design adapted to this board: the changed HDL files, the project file `fmcomms5_zc706.xpr` with its block design (`.srcs`, including an ILA for debugging) and the ADI HDL licence files |
| `FMCOMMS5_PS/system_top.xsa` | Hardware platform exported from that project (same bitstream as in the prebuilt package) |
| `FMCOMMS5_PS/FMCOMMS5/` | Dual-AD9361 application: Analog Devices no-OS AD9361 driver and FMCOMMS5 example (release `2023_R2`), with ADF5355 external-LO support and a four-channel TX/RX DMA example added for this board |
| `FMCOMMS5_PS/TCP_Server/` | lwIP TCP throughput server (Xilinx example, `lwip213` library from Vitis 2023.2) |
| `FMCOMMS5_PS/LED/`, `DDR_Test/`, `xusbps_intr_example_1/` | PS LED blink, PS DDR3 test and USB device example |

## Prepare the Vivado project

`FMCOMMS5_PL/` contains only the files that differ from the Analog Devices HDL repository; everything else comes from it unchanged.

1. Clone the Analog Devices HDL repository at the tested commit (branch `hdl_2023_r2`):

        git clone -b hdl_2023_r2 https://github.com/analogdevicesinc/hdl.git
        git -C hdl checkout d146370c10fdd55156de2bafdd9b24292c01b6e1

2. Copy this folder over it:

        cp -r <repo>/baremetal/FMCOMMS5_PL/. hdl/

3. Build the Analog Devices IP cores used by the design with Vivado 2023.2 (from a shell where `settings64.sh` of Vivado 2023.2 has been sourced):

        cd hdl/library
        for ip in axi_ad9361 axi_dmac axi_sysid sysid_rom util_pack/util_cpack2 util_pack/util_upack2 \
                  util_rfifo util_wfifo xilinx/util_clkdiv; do make -C $ip; done

4. Open `hdl/projects/fmcomms5/zc706/fmcomms5_zc706.xpr` in Vivado 2023.2. The project targets the XC7Z100-2FFG900 (`xc7z100ffg900-2`). Generate the bitstream and export the hardware with **File > Export > Export Hardware** (include bitstream).

The changed files are `projects/fmcomms5/zc706/system_top.v` and `system_constr.xdc` (pin-out of the two AD9361, the ADF5355 SPI and enable pins on this board) and `projects/common/zc706/zc706_system_constr.xdc` (ZC706-only constraints removed). `mem_init_sys.txt` is the system-ID memory file generated by the ADI scripts. The block design in `fmcomms5_zc706.srcs/` was changed in Vivado compared with `system_bd.tcl` (target device, ILA), so open the `.xpr` instead of running `make` in the project folder.

## Build the applications in Vitis 2023.2

1. Create a platform from `FMCOMMS5_PS/system_top.xsa` (or your own export): operating system standalone, processor `ps7_cortexa9_0`. For `TCP_Server`, add the `lwip213` library in the board support package settings.
2. Create an empty bare-metal C application for each folder and import its sources.
3. For `FMCOMMS5`, import the folders `ad9361`, `api`, `axi_core`, `iio`, `include`, `src`, `util` and `xilinx`, and add these include directories (ARM v7 gcc compiler > Directories): `ad9361`, `api`, `axi_core`, `iio`, `iio/iio_app`, `include`, `src`, `util`, `xilinx`. The build options are in `src/app_config.h` (`XILINX_PLATFORM`, `FMCOMMS5`, `DMA_EXAMPLE`) and the GPIO/SPI assignments in `src/parameters.h`.
4. Build and run over JTAG; the serial console is PS UART0, 115200 8N1.

Prebuilt files of all designs are in `7100_2XAD9361_FMCOMMS5-baremetal_prebuilt_Vivado2023.2.zip` on the Releases page.
